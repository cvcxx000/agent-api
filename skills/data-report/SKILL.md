# 数据报告技能

按下面顺序执行，不要跳步：

1. **确认输入**
   - `list_dir` 找到目标文件，`read_file` 读前 50 行，确认字段/分隔符。
2. **校验数据**
   - 用 `run_python` 统计行数、空值、重复值、异常值，把结果打印出来。
   - 如果统计结果和肉眼观察不一致，先查编码/分隔符问题，不要直接下结论。
3. **生成报告**
   - 用 `write_file` 写到 `outputs/report-<日期>.md`，结构固定为：
     - 数据概览（行数、字段、时间范围）
     - 质量检查（缺失/重复/异常）
     - 关键发现（3-5 条，每条都要能追溯到具体统计数字）
     - 下一步建议
4. **自检**
   - 重新 `read_file` 一遍产出的报告，确认没有占位符、没有 `TODO`、数字和统计结果一致。

约束：
- 报告里的每个数字都必须来自本会话真实跑出来的统计输出。
- 不要编造字段名；字段名以文件里实际出现的为准。
